PENDAHULUAN
LATAR BELAKANG
Industri kuliner dan pengoperasian restoran modern membutuhkan sistem pengolahan data yang cepat, terintegrasi, serta minim kesalahan manusia (human error). Operasional restoran harian melibatkan setidaknya tiga pilar utama yang saling berkaitan erat, yaitu: pengelolaan katalog menu (makanan utama, minuman segar, dan hidangan penutup), manajemen sumber daya manusia atau pegawai restoran (chef, pelayan, dan kasir), serta pencatatan transaksi pesanan pelanggan (makan di tempat, dibungkus, maupun layanan pesan antar).
Jika pencatatan operasional ini dilakukan secara konvensional atau menggunakan pemrosesan data linier berukuran tunggal, risiko ketidakselarasan harga, kekeliruan jadwal kerja pegawai, hingga kesalahan pengantaran pesanan akan sangat tinggi. Oleh karena itu, penerapan paradigma Object-Oriented Programming (OOP) berbasis bahasa pemrograman Java menjadi solusi fundamental. Melalui OOP, seluruh komponen bisnis restoran dapat dimodelkan menjadi kelas-kelas terisolasi yang modular, aman (melalui enkapsulasi data), dapat diwariskan, serta adaptif terhadap perubahan sistem di masa depan.
TUJUAN PRAKTIKUM
Membangun aplikasi konsol Java Sistem Informasi Restoran yang mampu mengelola data menu, pegawai, dan pesanan secara terstruktur menggunakan penyimpanan dinamis `ArrayList`.
Menerapkan secara utuh 5 pilar utama OOP, yaitu Class & Object, Encapsulation, Inheritance, Polymorphism, serta Abstraction & Interface.
Merancang arsitektur perangkat lunak menggunakan 4 diagram UML (*Class Diagram*, *Use Case Diagram*, *Sequence Diagram*, dan *Activity Diagram*) yang selaras 100% dengan kode Java yang dieksekusi.
Membagi tanggung jawab pengerjaan modul secara adil kepada 3 anggota kelompok (1 *Parent Abstract Class* dan 3 *Child Class* per anggota).
DESKRIPSI SINGKAT SISTEM
Sistem Informasi Restoran merupakan aplikasi berbasis antarmuka baris perintah (CLI) interaktif. Aplikasi ini menyediakan 6 fungsi operasional utama: (1) Input Data Menu Restoran, (2) Input Data Pegawai Restoran, (3) Input Data Pesanan Pelanggan, (4) Tampilkan Semua Data secara polimorfik, (5) Ubah Data (*Update*) berdasarkan ID objek, dan (6) Keluar dari Sistem.

BAB III
IMPLEMENTASI DAN PENGUJIAN
3.1 IMPLEMENTASI KONSEP OOP
Berikut adalah penjelasan penerapan kelima konsep Pemrograman Berorientasi Objek pada aplikasi Sistem Informasi Restoran:
1. Class dan Object
Class digunakan sebagai cetak biru (blueprint) dari entitas restoran, sedangkan Object adalah instansiasi nyata dari class tersebut menggunakan kata kunci "new".
Kode di atas membuat objek baru dari class MenuMakanan dan menyimpannya ke dalam koleksi ArrayList daftarMenu.
2. Encapsulation
Encapsulation diterapkan dengan memberikan hak akses "private" pada seluruh atribut di dalam parent class (MenuRestoran, Pegawai, dan Pesanan) agar data tidak dapat diakses sembarangan dari luar class. Akses pembacaan dan pengubahan nilai dilakukan melalui method "public" Getter dan Setter.
Atribut namaMenu dan harga dilindungi dengan modifier private dan hanya dapat dimodifikasi saat fitur Ubah Data memanggil setNamaMenu() atau setHarga().
3. Inheritance (Pewarisan)
Inheritance diterapkan menggunakan kata kunci "extends" di mana setiap parent class memiliki 3 child class yang mewarisi atribut serta method induknya. Constructor child class memanggil constructor induk menggunakan kata kunci "super(...)".
Class Chef mewarisi atribut idPegawai, namaPegawai, dan shiftKerja dari class induk Pegawai tanpa harus mendeklarasikan ulang atribut tersebut.
4. Polymorphism
Polymorphism diterapkan melalui method overriding (@Override) pada setiap child class. Ketika method tampilkanData() dan tampilkanAktivitas() dipanggil melalui referensi parent class di dalam perulangan ArrayList, program secara dinamis mengeksekusi method sesuai jenis objek subclass-nya.
Satu perintah p.tampilkanData() menghasilkan keluaran tugas yang berbeda tergantung apakah objek di dalamnya adalah Chef, Pelayan, atau Kasir.
5. Abstarction dan Interface
Interface LayananRestoran mendefinisikan kontrak method tampilkanAktivitas(), sedangkan MenuRestoran, Pegawai, dan Pesanan dirancang sebagai abstract class yang mendefinisikan kerangka dasar dan method abstract untuk diimplementasikan oleh subclass masing-masing.
3.2 IMPLEMENTASI PROGRAM
Program utama (Main.java) mengintegrasikan komponen Scanner untuk membaca input pengguna dan tiga buah ArrayList untuk menampung objek MenuRestoran, Pegawai, dan Pesanan. Perulangan do-while dan struktur switch-case digunakan untuk mengatur navigasi ke-6 menu aplikasi.
3.3 HASIL PENGUJIAN PROGRAM
Berikut adalah hasil pengujian fungsionalitas aplikasi Sistem Informasi Restoran saat dijalankan:
1. Tampilan Menu Utama Aplikasi: Menampilkan 6 opsi menu interaktif kepada pengguna.
2. Proses Input Data: Pengguna menginputkan data Menu (Makanan/Minuman/Dessert), Pegawai (Chef/Pelayan/Kasir), dan Pesanan (Dine-In/Take-Away/Delivery).
3. Proses Pengolahan & Ubah Data: Pengguna mengubah data yang sudah tersimpan menggunakan ID.
4. Output Program (Tampilkan Semua Data): Menampilkan seluruh data secara polimorfik ke layar konsol.

4.2 KENDALA DAN SOLUSI
Selama proses pengerjaan proyek UTS PBO ini, beberapa kendala yang dihadapi beserta solusinya adalah sebagai berikut:
1. Kendala Pembacaan Input String Setelah Angka pada Scanner: Saat menggunakan method input.nextInt() untuk memilih menu atau memasukkan harga, baris input berikutnya (input.nextLine()) sempat terlewat otomatis. Solusi: Menambahkan baris perintah input.nextLine() tepat setelah pemanggilan input.nextInt() untuk membersihkan karakter newline (enter) pada buffer Scanner.
2. Kendala Penyelarasan Struktur Class Antar Anggota Kelompok: Pada tahap awal, masing-masing anggota menggunakan penamaan method yang berbeda-beda sehingga menyulitkan pemanggilan di class Main. Solusi: Menyepakati satu Interface bersama (LayananRestoran.java) dan menyamakan pola method pada ketiga parent class sebelum mulai menulis kode child class.
